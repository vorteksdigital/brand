# Security Policy

## Supported version

Security fixes are applied to the current production version on the
`development` branch.

## Report a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/vorteksdigital/brand/security/advisories/new).
Include the affected URL or component, reproduction steps, impact, and any
suggested remediation.

Do not open a public issue or disclose the vulnerability publicly before it has
been investigated and fixed. We will acknowledge the report and coordinate any
required disclosure through the private advisory.
