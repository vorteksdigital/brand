# Content model

- Users: authenticated name/email plus `admin` or `editor` role. Admins manage
  users; editors manage their own profile and normal content.
- Media: images only, responsive sizes, focal point, dimensions generated by
  Payload, caption, credit, and required alt unless explicitly decorative.
- Pages: title, root-safe slug (`home` renders `/`), hero, flexible blocks, SEO,
  drafts, autosave, scheduled publishing, preview, 50 versions.
- Posts: title, slug, rich content, hero image, authors, categories, explicit
  related posts, SEO, publish date, drafts, autosave, preview, 50 versions.
- Categories: title, slug, description; nested paths use Payload nested-docs.
- Globals: Header, Footer, Site Settings organisation/contact/social/SEO defaults.

Blocks: CTA, Content, Media, Archive, Form; post rich text also supports Banner,
Code, and Media. Renderer ignores unknown blocks safely.
