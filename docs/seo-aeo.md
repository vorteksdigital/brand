# SEO and AEO

Payload SEO fields feed Next Metadata, canonical URLs, Open Graph, and social
images. Published-only XML sitemaps, dynamic robots exclusions, RSS, redirects,
custom 404, SSR content, Breadcrumb/Article markup, and organisation/site
defaults form technical foundation. Never claim ratings, credentials, or facts
not stored in CMS.

Editor checklist: unique 50–60 character title; useful 150–160 character
description; one descriptive H1; direct answer near start; logical H2/H3;
descriptive links; primary-source citations; author/date; accurate image alt;
social image; stable slug/canonical; preview and freshness review.
